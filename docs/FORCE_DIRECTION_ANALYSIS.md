# 🔍 电磁力异常增加问题分析

## 📊 你观察到的数据

### 电磁力随z位置的变化
```
z=45.0mm:   0→0.002s: 1.9664 → 1.9658 mN
z=45.1mm:   0→0.002s: 4.4367 → 4.4404 mN
z=47.0mm:   0→0.002s: 4.9386 → 4.9393 mN
```

### 异常现象
- ⚠️ **z增加（磁球远离），力反而增加**
- z=45mm: ~1.97 mN
- z=45.1mm: ~4.44 mN（增加了125%）
- z=47mm: ~4.94 mN（继续增加）

### 物理预期
✅ **正常情况**：磁球远离 → 磁场减弱 → 力应该**减小**

❌ **你的结果**：磁球远离 → 力反而**增大**

**结论**：数据违反物理规律！

## 🔍 可能的原因分析

### 1. 力的方向定义错误 🔴 最可能
**问题**：可能计算的是反向的力

**检查项**：
- 力的计算表达式中的符号
- 积分域的法向量方向
- 坐标系定义（右手系vs左手系）

**例如**：
```
错误：F = -∫ σ·n dS  （多了一个负号）
正确：F = ∫ σ·n dS
```

### 2. 参数z_sphere的定义问题 🔴 很可能
**可能情况A**：z_sphere定义反了
```
错误：z_sphere = 50 - actual_z  （反向）
正确：z_sphere = actual_z
```

**可能情况B**：几何构建中使用了 `-z_sphere`
```
球心位置：(x, y, -z_sphere)  而不是 (x, y, z_sphere)
```

### 3. 磁通密度B的方向错误
**问题**：磁场方向可能设置反了

**检查项**：
- 永磁体的磁化方向
- 边界条件中的磁场方向
- 材料属性中的磁化向量

### 4. 积分面（域）选择错误
**问题**：可能在错误的表面上积分

**检查项**：
- 是否在正确的几何面上积分
- 积分域是否包含了不该包含的部分
- 法向量是否指向正确

## 🎯 最可能的问题

根据你的数据特征，**最可能的原因**是：

### 原因A：z_sphere参数定义反向
```
当前（错误）：
  z_sphere = 45  → 球体实际在 z = -45 位置
  z_sphere = 47  → 球体实际在 z = -47 位置（更近！）

应该（正确）：
  z_sphere = 45  → 球体在 z = +45 位置
  z_sphere = 47  → 球体在 z = +47 位置（更远）
```

**验证方法**：
在GUI中查看3D几何，观察球体位置是否随z_sphere增加而**向上移动**还是**向下移动**。

### 原因B：力的符号错误
```
当前（错误）：计算了 -F（负的力）
正确：应该计算 +F

或者：
当前（错误）：法向量指向内部（n_inward）
正确：应该指向外部（n_outward）
```

## 📝 具体检查代码

### 检查1：参数定义
在COMSOL中查找类似这样的定义：
```
z_sphere = 50[mm] - z_actual  ← 如果有减法，就是反了！
```

应该是：

### 检查2：几何定义
球心应该是：
```
正确：(0, 0, z_sphere)
错误：(0, 0, -z_sphere)  ← 注意这个负号！
```

### 检查3：力的积分
应该是：
```
正确：reacf(comp1.emqa.Tx, 'maxwell')
错误：-reacf(comp1.emqa.Tx, 'maxwell')  ← 注意负号！
```
