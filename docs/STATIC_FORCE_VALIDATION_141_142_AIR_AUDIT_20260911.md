# 141/142 静态磁力跳变审计

日期：2026-09-11

源模型：`H:\comsolcc\z120_xsphere26_air200_mesh1.mph`  
本轮范围：仅固定姿态 `phi=0°`、`z=141/142 mm`；未启动全周期、未增加其他高度、未恢复瞬态。

## 结论

1. 最终组件三维测量已修正，之前的几何诊断错误来自 `getBoundingBox()` 顺序误读。COMSOL 6.3 返回顺序为 `[xmin,xmax,ymin,ymax,zmin,zmax]`，长度单位为模型单位 mm。
2. 141 与 142 的几何身份检查通过：只有磁球沿 z 方向移动；圆柱、钢片、外部空气域、Force Calculation 选择保持不变。
3. ON 和 AIR 对照均出现几乎相同的 141→142 跳变：`Delta_ON=1.162718318577 mN`，`Delta_AIR=1.162759059667 mN`。因此该跳变不能解释为磁球剩磁作用，优先应继续检查空间离散、模型内部接口/约束和求解状态依赖。
4. 严格容差尝试没有通过：PARDISO、`study.stat.usestol=on`、`stol=1e-6` 的日志给出 `LinErr≈0.0014`、`LinRes≈3.7e-14`，COMSOL 报相对误差高于容差并返回不收敛。`stol=0.01` 的结果只能作为可重复工程基线，不能称为精度已验证。
5. 磁标势参考节点 `zsp1` 在 API 中没有发现显式边界/点选择，仅看到约束属性。没有在本轮凭猜测添加新的点约束或把外边界改为 `Vm=0`，避免改变物理问题；该项应在 GUI/官方模型树中进一步确认。

## 求解器/矩阵证据

严格方案已经实际执行过：

```text
Stationary study step: usestol=on, stol=1e-6
FullyCoupled: linsolver=dDef
Direct dDef: linsolver=pardiso
LinErr ≈ 0.0014
LinRes ≈ 3.7e-14
```

COMSOL 返回“相对误差高于相对容差、返回的解不收敛”。因此 `LinRes` 很小不等于 `Fx` 已达到同等相对精度；当前 `stol=0.01` 结果仅为可重复基线。没有关闭错误检查，也没有用失败解填充结果。

## 下一步边界

本轮停止在最小诊断集。因为 AIR 物理不变性没有通过，暂不扩展 z、全周期角度或寻找翻转区间。下一步应在保持几何、物理和力表达式不变的前提下，针对同一 141/142 姿态检查：

- 是否存在有效且固定位置的磁标势参考；
- 近场空气、磁体表面和 Force Calculation 相关区域的连续局部网格收敛；
- 同一高度的模型/网格/数据集是否真正复用；
- 必要时用合法空气闭合包络面与内置 Force Calculation 对照。

不得用新增外边界 `Vm=0`、修改磁导率/磁化极性、改变间隙或挑选有利结果来消除跳变。
