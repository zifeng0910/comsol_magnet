# 141/142 固定姿态稳态求力验证

## 结论

在不扩展 z 扫描、不使用瞬态 `sol2/t1` 的条件下，重新建立独立 Stationary study，先配置实际启用的 PARDISO，再求解并立即读取 `mfnc.Forcex_force_magnet`。`stol=1e-6` 在当前网格和矩阵上不能收敛，但 `stol=0.01` 基线可以稳定复算。

静态基线下，141 mm 与 142 mm 的符号翻转被重现：141 为负，142 为正。0°、180°、360°的同姿态值基本一致，说明这次符号差异不是瞬态首步初始化造成的表格读取假象。不过由于 1e-6 精度失败，数值精度仍未完成最终验收。

## 真实模型配置核对

- 源模型：`H:\comsolcc\z120_xsphere26_air200_mesh1.mph`
- `x_sphere=26 mm`，`alpha=30 deg`，`z_sphere` 是球心的绝对 z 坐标。
- 磁球磁化特征：`mfnc/mfc2`，实际选择域 `[4]`。
- Force Calculation：`mfnc/fcal1`，实际选择域 `[3]`。
- 材料：Air `mat4` 域1；N52 `mat3` 域3、4；钢片 `mat5` 域2。
- 本轮为固定几何、外部规定磁化姿态的磁场问题；未发现固体运动方程、涡流、磁滞或温度演化作为本轮求解必须保留的动态项。
- 源模型中存在 `RotatingDomain rot1`。固定姿态分支将其移除并明确记录为“静态冻结分支的既有清理”，不是新的求解修复证据。

## 姿态表达式

使用：

```text
sin(alpha)
cos(alpha)*cos(phi)
-cos(alpha)*sin(phi)
```

因此：

- phi=0°：`(0.5, 0.866025403784, 0)`
- phi=180°：`(0.5, -0.866025403784, 0)`
- phi=360°：与 phi=0° 相同，仅有浮点舍入量级的 z 分量。

## 重复性与闭合

- 141：0°与360°差约 `2e-12 mN`；同会话 0°复算差约 `1.6e-11 mN`。
- 142：0°与360°差约 `2e-12 mN`；同会话 0°复算差约 `1e-12 mN`。
- 0°与180°的变化：141 约 `4.04e-5 mN`，142 约 `4.22e-4 mN`。
- 0°/360°闭合很好，但这只验证固定姿态重复性，不等于完成空间网格收敛或完整周期动态验证。

## 1e-6 精度尝试及失败证据

- 原错误控制方式：PARDISO、`s1.control=user`、`s1.stol=1e-6`，141/phi=0 失败。
- 修正为模型原生层级：`study.stat.usestol=on`、`study.stat.stol=1e-6`、`s1.control=stat`，141/phi=0 仍失败。
- PARDISO 日志给出相对误差约 `0.0014--0.0015`，高于 `1e-6`，并报告线性求解器警告、迭代求精和未收敛解。
- MUMPS 单点对照同样未达到 1e-6，报告相对误差约 `8.8`。

所以当前可交付的是“可复算静态工程基线”，不是 1e-6 精度验收结果。原始 138--145 瞬态扫描仍标记为数值准确性待验证。
